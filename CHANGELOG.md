# Changelog

## 1.0.0

- Refactored the original university lab into a layered Java 17 project.
- Added repository and service layers.
- Added task lifecycle states, UUIDs and timestamps.
- Added task search/sort, completion flow and helper score updates.
- Added PBKDF2 password hashing and legacy password migration.
- Added PDF certificate upload/admin verification.
- Added admin analytics, custom chart and CSV export.
- Added atomic file persistence and audit logging.
- Added smoke tests, run/build scripts and GitHub Actions CI.
